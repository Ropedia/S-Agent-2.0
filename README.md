# S-Agent 2.0

Project page for **Spatial Reasoning with a General Coding Agent**, with benchmark results, videos and 11 interactive agent trajectories.

## Local preview

Run from the repository root:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). No build step is required.

## Files

- `index.html`: project page.
- `static/`: styles, scripts, figures and videos.
- `trajectories/`: standalone viewer, case data and images.

The site uses relative asset paths and can be served from a repository subdirectory. `.nojekyll` supports direct static hosting on GitHub Pages.
