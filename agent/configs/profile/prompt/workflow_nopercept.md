## How to work this problem

1. Inspect the relevant frame(s) and restate the target object or relation in
   the terms used by the question.
2. Identify the reference frame. In the question, `Figure N` corresponds to
   zero-based `frame N-1.png`; left/right/front/behind depend on the reference
   viewpoint.
3. Use only the available image evidence. Do not infer precise distances,
   heights, depths, sizes, or camera motion from a number that the image cannot
   support; state your best visual conclusion instead.
4. Keep the answer file current while investigating. Re-read the question and
   the answer file before finishing.
